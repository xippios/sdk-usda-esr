# Upstream documentation snapshot — USDA FAS Export Sales Reporting

Source of truth for every endpoint wrapper (ADR-0003). Files in this directory are
fetched from https://apps.fas.usda.gov/opendatawebV2/ by `/refresh-upstream`, never edited by hand, and
refreshed deliberately by PR so that changes show up as diffs.

names and semantics the wrappers rely on.

## Files

`Fetched` is the UTC time of the run in ISO 8601 with an explicit `Z`
(`2026-10-24T09:15:00Z`). A table with merged cells (`rowspan`, `colspan`) or a table
nested in it, which a Markdown pipe table cannot hold, is kept as its HTML in the
Markdown file, and its row's note says so.
